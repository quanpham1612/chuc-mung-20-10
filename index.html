Trang cần JavaScript để hoạt động Bản xem trước trong ứng dụng Tệp trên iPhone/iPad có thể không chạy được phần tương tác của trang này. Nội dung và chức năng gốc vẫn được giữ nguyên trong file. Để dùng đầy đủ, hãy mở trang qua Safari từ một địa chỉ HTTPS (đăng tải file HTML lên dịch vụ lưu trữ web trước); chỉ đổi CSS hoặc đổi tên file sẽ không khắc phục được nếu bản xem trước chặn JavaScript.
